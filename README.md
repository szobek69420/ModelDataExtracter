ModelDataExtracter is a program used for extracting the geometry data of 3d models and packing it into an simpler file format for [Morbius-Motorsport-2026](https://github.com/szobek69420/Morbius-Motorsport-2026).

To run the program, open a terminal in the root directory of the project and type:
```
gradlew run
```
